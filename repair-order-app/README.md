# ระบบรับแจ้งซ่อม (Google Drive + Google Sheets)

เว็บแอปสำหรับพนักงานรับแจ้งซ่อม พร้อมแนบภาพได้ 3 รูป, เลขใบงานรันอัตโนมัติ, เก็บรูปใน Google Drive และเก็บรายการใน Google Sheets พร้อมหน้าพิมพ์ใบงาน A4 ตามแบบตัวอย่าง

## สิ่งที่ระบบทำ

- ฟอร์มข้อมูลผู้แจ้ง, บ้าน/พื้นที่, งานซ่อม และรายละเอียด
- จำกัดรูป JPEG/PNG ไม่เกิน 3 รูป รูปละ 6 MB
- สร้างเลขใบงานรูปแบบ `YYMM-0001` และเริ่มเลขใหม่รายเดือนอย่างปลอดภัยแม้มีหลายคนกดพร้อมกัน
- สร้างโฟลเดอร์รูปแยกตามเลขใบงานใน Google Drive
- บันทึกทุกรายการลงชีต `Repair Orders` เพื่อใช้เป็นรายงาน/กรอง/มอบหมายงาน
- เปิดใบงานพิมพ์พร้อมข้อมูลและรูปแนบได้ทันที

## ติดตั้งขึ้น GitHub และ Google Apps Script

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดโฟลเดอร์ `repair-order-app` นี้
2. เปิด [script.google.com](https://script.google.com) → **New project**
3. สร้างไฟล์ `Code.gs`, `Index.html`, `Print.html`, `appsscript.json` แล้ววางเนื้อหาจาก repository ให้ตรงชื่อไฟล์
4. ใน Apps Script เลือกฟังก์ชัน `setup` แล้วกด Run หนึ่งครั้ง เพื่ออนุญาตสิทธิ์และสร้าง Google Sheet/โฟลเดอร์รูปอัตโนมัติ
5. เลือก **Deploy → New deployment → Web app** ตั้ง Execute as: **Me** และเลือกผู้มีสิทธิ์เข้าใช้ตามนโยบายบริษัท จากนั้น Deploy
6. ส่งลิงก์ Web app ให้พนักงานใช้งาน

> ลิงก์ Google Sheet จะปรากฏจากผลลัพธ์ของ `setup` ใน Execution log และสามารถเปิดผ่านเมนู Apps Script → Executions ได้

## การทำงานของเลขรัน

ตัวอย่าง วันที่ ต.ค. 2026: `2610-0001`, `2610-0002` … เดือนถัดไปจะเริ่ม `2611-0001` อัตโนมัติ หากต้องการให้รันต่อข้ามเดือน ให้แก้ฟังก์ชัน `nextTicketNo_`.

## การจัดการงานหลังรับแจ้ง

เปิดชีต `Repair Orders` เพื่อกรองรายการ, เปลี่ยนสถานะ และกรอกคอลัมน์สำหรับเจ้าหน้าที่ เช่น ผู้รับผิดชอบ, วันนัดหมาย, รายละเอียดดำเนินการ และผลการปฏิบัติงานได้โดยตรง จากนั้นเปิดลิงก์ใบงานเดิมเพื่อพิมพ์ข้อมูลล่าสุดพร้อมรูปแนบ

## หมายเหตุสิทธิ์

ระบบเก็บไฟล์โดยบัญชีที่ Deploy แอป จึงควร Deploy ด้วยบัญชี Google Workspace กลางของโครงการ และจำกัดสิทธิ์เว็บแอปให้เฉพาะโดเมนบริษัทเมื่อเป็นข้อมูลลูกค้า.
